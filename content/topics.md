# Topics

Example sections below show sidebar hierarchy (H1–H4), link styling, and build helpers.

## Getting started

Use `##` and `###` headings to organize content. The sidebar picks up H1–H4 automatically.

### Markdown links

**Link:** [example.com](https://example.com/)

External links open in a new tab. Video hosts get a play icon on hover.
